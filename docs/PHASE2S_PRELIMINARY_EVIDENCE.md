# Phase 2S preliminary evidence

**Observed classification:** A: observed evidence supports a PALMAR_SECURED advantage in the paired formal experiment.

The formal experiment completed 4000 trials. FINGERTIP achieved 0/2000 valid-trial BOTH_RETAINED outcomes and PALMAR_SECURED achieved 65/2000. The absolute difference was 3.2500 percentage points; the matched-pair bootstrap 95% interval was [0.0115, 0.055999999999999994], and exact McNemar p was 5.421010862427522e-20.

These are directly initialized endpoint states. No transfer dynamics, scalar J, wrist control, third object, or RL training was implemented.
