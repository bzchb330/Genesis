# Phase 2T rationale

Phase 2S demonstrated a strong difference in digit availability. Every validated FINGERTIP endpoint used three load-bearing fingers and left one free finger, whereas every PALMAR_SECURED endpoint left at least two fingers free. Consequently all 2,000 Phase 2S FINGERTIP formal cells were classified as `INSUFFICIENT_FREE_DIGITS_PRECHECK` without dynamic second-grasp execution.

Phase 2S therefore demonstrates resource recovery and second-grasp eligibility. It does not isolate the dynamic effect of palmar securing after equal digit availability is imposed.

Phase 2T supplies that control by comparing stable `FINGERTIP_ELIGIBLE_2FREE` and `PALMAR_SECURED_2FREE` endpoints having exactly two load-bearing and two free fingers, with identical free-finger identity inside each matched topology stratum. Object geometry, 0.08 kg masses, physics, thresholds, fixture release, controller semantics, and outcome definitions remain identical to Phase 2S.

No scalar resource metric J, transfer controller, finger gaiting, wrist controller, third object, reward tuning, or reinforcement learning is introduced.
