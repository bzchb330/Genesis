# Phase 2S rationale: half-scale object geometry

Phase 2R remains the preserved LARGE-object baseline. Its objects visually
occupied a large fraction of the Allegro hand and palm, strongly constraining
multi-object storage and second acquisition.

Phase 2S reduces every physical linear dimension of object A and object B by
exactly 50% while retaining each object's 0.08 kg mass and all other validated
physics, controller gains, thresholds, hand geometry, and task semantics. This
isolates geometric scale rather than preserving material density. A future
same-density mass-scaling study would be a separate sensitivity experiment.

All endpoint states, resource components, B workspace evidence, controller
calibration, and formal trials are regenerated under the new geometry. Phase 2R
states may provide proposal seeds but cannot enter Phase 2S as validated data.

No fingertip-to-palm transfer trajectory is simulated. No scalar J, wrist
controller, third-object task, reward redesign, or reinforcement learning is
defined here.
