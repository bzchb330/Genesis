# Phase 2T-R rationale

Phase 2T showed that free-digit number alone is insufficient. Although 150 stable endpoints each left exactly two digits free, 148 left index+middle free and that pair achieved zero strict B-only acquisitions in 4,096 candidates. The two remaining endpoints used middle+ring support and left index+thumb free, the same pair for which Phase 2S had demonstrated strict B-only acquisition.

Phase 2T-R therefore controls both free-digit count and free-digit identity. Every primary endpoint must have exactly middle+ring as the load-bearing A fingers at the unchanged 0.20 N threshold and exactly index+thumb free. Incidental sub-threshold contacts are recorded but do not alter this classification.

The experiment preserves the Phase 2S/2T scene, physics, object dimensions and masses, fixture semantics, stability thresholds, and success criteria. It tests endpoint-state topology only. It does not simulate transfer, add wrist control or finger gaiting, train a policy, run mass sensitivity, or define a scalar resource metric.
